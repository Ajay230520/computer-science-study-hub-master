# Software Engineering

## Roadmap
- Requirements, user stories, acceptance criteria, traceability.
- Architecture, modularity, cohesion, coupling, design patterns.
- API contracts, validation, error handling, versioning.
- Unit/integration/e2e tests, test doubles, testing strategy.
- Git workflows, code review, CI/CD, release safety.
- Reliability, observability, incident learning, maintainability.
- Threat modeling, privacy by design, secure development.

Case studies must separate verified public evidence from illustrative scenarios and explain trade-offs and constraints.
