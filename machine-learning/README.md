# Machine Learning & Artificial Intelligence

## Roadmap
1. Data, features, labels, and problem framing.
2. Supervised, unsupervised, and reinforcement learning.
3. Train/validation/test splits, leakage, baselines, reproducibility.
4. Regression and classification.
5. Metrics: confusion matrix, precision, recall, F1, ROC/PR curves, calibration.
6. Overfitting, regularization, cross-validation, bias–variance.
7. Feature engineering, preprocessing, imbalanced data.
8. Neural networks and deep learning.
9. Interpretability, fairness, robustness, privacy, deployment monitoring.

Every algorithm page should describe assumptions, objective, workflow, failure modes, baseline comparisons, and reproducible examples.
