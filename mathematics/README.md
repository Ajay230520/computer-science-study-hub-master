# Mathematics for Computer Science & Machine Learning

Build mathematical reasoning for algorithms, ML, image processing, data science, and research papers.

## Roadmap
1. **Discrete mathematics:** logic, propositions, sets, functions, relations, combinatorics, induction, proofs, graphs.
2. **Probability and statistics:** sample spaces, events, counting, conditional probability, independence, Bayes' theorem, random variables, distributions, expectation, variance, sampling, estimation, hypothesis tests.
3. **Linear algebra:** vectors, matrices, systems of equations, transformations, rank, basis, eigenvalues/eigenvectors, orthogonality, SVD.
4. **Calculus:** limits, derivatives, partial derivatives, chain rule, gradients, integrals, multivariable calculus.
5. **Optimization:** objective functions, convexity, gradient descent, constraints, regularization, convergence.
6. **Information theory:** entropy, cross-entropy, KL divergence, mutual information.

For each subject: intuition → definition → notation → worked examples → edge cases → practical code/visualization → applications → exercises and review.
