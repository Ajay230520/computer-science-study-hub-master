# Database Systems

## Roadmap
- Relational model, keys, constraints, normalization.
- SQL querying and query semantics.
- Indexes, B-trees, selectivity, query plans.
- Transactions, ACID, isolation, locking, concurrency.
- Replication, partitioning, distributed data, recovery.
- Data modeling, migrations, backups, secure access.

Use realistic schemas and testable SQL. Explain trade-offs in latency, write cost, storage, consistency, and operational complexity.
