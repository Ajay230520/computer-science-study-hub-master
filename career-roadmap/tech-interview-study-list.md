# Tech Interview Study List — Reference Notes

**Source document:** *Tech Interview Study List by codersoni* (10-page PDF supplied by Ajay).  
**Purpose:** A supplementary interview-preparation checklist, separate from the official M.Tech Semester 1 syllabus.  
**Source attribution:** Created by codersoni / Shubham, as stated in the source PDF. These notes summarize the checklist; they are not an official syllabus or a claim that every topic is required for every role.

## 1. Git and collaboration

Practise repository setup and everyday commands: `git init`, `clone`, `status`, `add`, `commit`, `push`, `pull`, `fetch`, `branch`, `switch`, `merge`, `rebase`, `log`, `diff`, `stash`, `reset`, `revert`, `cherry-pick`, `tag`, `remote`, `restore`, `reflog`, `blame`, `bisect`, `.gitignore`, merge-conflict resolution, merge strategies, reset modes, branching strategies, pull requests, and code review.

## 2. System design

The PDF lists client-server architecture, vertical/horizontal scaling, load balancing, caching, sharding, replication, SQL vs NoSQL, CAP, consistency models, indexing, queues, monoliths vs microservices, API styles and gateways, rate limiting, consistent hashing, proxies, CDNs, fault tolerance, observability, capacity estimation, latency vs throughput, ACID vs BASE, isolation levels, normalization, cache eviction and write strategies, idempotency, distributed transactions, consensus, quorum, pub/sub, CQRS, service discovery, circuit breakers, backpressure, Bloom filters, gossip, real-time communication patterns, unique IDs, authentication/authorization, partitioning, object storage, search, geospatial indexing, analytics platforms, SLO/SLA/SLI, disaster recovery, and classic designs such as URL shorteners, chat, news feeds, ride sharing, streaming, notifications, and rate limiters.

## 3. Linux

Practise navigation and file operations; text viewing/searching; permissions and ownership; process and disk/memory inspection; archives; links; service logs; SSH/SCP; HTTP/download tools; network diagnostics; scheduled tasks; background jobs; environment variables; pipes/redirection; text processing; open-file inspection; mounts; package managers; terminal editors; permission modes such as 755/644; and basic shell scripts.

## 4. JavaScript and TypeScript

Topics include variables and types, coercion, functions, scope/hoisting, closures, `this`, prototypes/classes, array methods, objects/destructuring, spread/rest, callbacks, promises, async/await, the event loop, DOM and event propagation, modules, errors, Fetch/JSON, equality and truthiness, higher-order functions, `call/apply/bind`, currying, debounce/throttle, memoization, microtasks vs macrotasks, promise combinators, iterators, Map/Set and weak collections, symbols, optional chaining/nullish coalescing, shallow vs deep copies, immutability, constructors, memory leaks/garbage collection, browser storage/cookies, CORS, regular expressions, date APIs, polyfills, strict mode, workers, Node.js basics, and TypeScript basics.

## 5. AWS

The checklist names EC2, S3, IAM, VPC, EBS, Elastic Load Balancing, Auto Scaling, Route 53, RDS, DynamoDB, Lambda, EKS, CloudFront, CloudWatch, SQS, SNS, API Gateway, ECS/Fargate, CloudFormation/Terraform, Aurora, ElastiCache, KMS/Secrets Manager, EventBridge, Step Functions, Cognito, Kinesis, Redshift/Athena, Elastic Beanstalk, CI/CD services, CLI/SDKs, Regions/AZs/edge locations, security groups vs network ACLs, S3 storage classes/lifecycle, shared responsibility, Well-Architected Framework, and cost management.

## 6. AI and machine learning

The list covers ML basics; supervised/unsupervised learning; neural networks and deep learning; train/validation/test splits; overfitting/underfitting; loss and gradient descent; NLP, tokenization, embeddings, transformers/attention, LLMs, prompting, fine-tuning, RAG, vector databases, agents/tool use, RLHF, evaluation, AI safety, deployment/inference, regression/classification, feature engineering, bias-variance, regularization, cross-validation, metrics, tree ensembles, clustering/PCA, backpropagation/activations, optimizers, CNNs, RNNs/LSTMs, transfer learning, sampling controls, hallucinations, PEFT/LoRA, quantization/distillation, retrieval pipelines, function calling/structured outputs, MCP, multi-agent systems, multimodal and diffusion models, prompt injection/guardrails, data leakage/quality, MLOps/LLMOps, and responsible AI.

## Suggested use in this study hub

- Treat this as a **career-interview checklist**, not as a replacement for GTU/LDCE subject syllabi.
- Prioritize topics against the target job description and current skill gaps rather than trying to master everything at once.
- For the user's full-stack/backend direction, begin with Git workflows, JavaScript/TypeScript fundamentals, Linux basics, API/database/system-design fundamentals, and practical ML/AI concepts as relevant to a role.
- Track a topic as reviewed only after completing practice or explaining it accurately; this reference alone is not evidence of mastery.
