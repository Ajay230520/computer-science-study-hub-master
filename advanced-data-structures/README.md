# Advanced Data Structures

## Roadmap
1. ADTs, interface versus implementation, asymptotic notation.
2. Hash tables, collision handling, load factor, resizing.
3. Binary search trees and balanced trees (AVL, red-black).
4. Heaps and priority queues.
5. Skip lists and probabilistic balancing.
6. 2–3 trees, B-trees, B+ trees.
7. Tries, disjoint-set union, range-query structures as needed.
8. Amortized analysis and operation trade-offs.

For each structure include invariants, operations, worked traces, expected/worst-case time and space, implementation, tests, and realistic selection criteria.
