# Digital Image Processing

## Roadmap
1. Image representation, sampling, quantization, resolution, color spaces.
2. Spatial and frequency domains; Fourier transform.
3. Intensity transformations and histogram processing.
4. Filtering, convolution, smoothing, sharpening, edge detection.
5. Restoration, noise models, deblurring.
6. Segmentation, morphology, connected components.
7. Feature extraction and object recognition foundations.
8. Evaluation metrics and experimental design.
9. Practical labs with Python and openly licensed/sample images.
