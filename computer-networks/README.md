# Computer Networks

## Roadmap
1. OSI and TCP/IP models.
2. LAN technologies and network devices.
3. Ethernet, ARP, IP, subnetting, IPv4 header.
4. Routing and forwarding.
5. TCP, UDP, ports, DNS, DHCP, HTTP/HTTPS, TLS.
6. Wireless, high-speed networking, congestion, performance.
7. Defensive network security and troubleshooting.

Use packet-flow diagrams, worked subnetting, command-line labs, realistic debugging cases, and security exercises only on systems you own or are authorized to test.
