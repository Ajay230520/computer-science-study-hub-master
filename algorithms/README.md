# Algorithms and Complexity

## Roadmap
- Problem specifications, correctness, loop invariants, proof techniques.
- Asymptotic analysis: O, Omega, Theta, best/average/worst cases.
- Searching and sorting.
- Recursion, divide-and-conquer, greedy algorithms, dynamic programming.
- Graph traversal, shortest paths, spanning trees, flows as needed.
- Randomized algorithms and amortized analysis.

Include correctness reasoning and complexity—not only code—and discuss input constraints and trade-offs.
